# Archief van de eerste oefeningen

De map eerste_versie/ bewaart de oorspronkelijke notebooks 01–04, hun docentversies, brongegevens en Wokwi-code. Notebook 00 en de toenmalige configuratie zijn als referentiekopie toegevoegd; de actieve exemplaren van notebook 00 blijven op hun oorspronkelijke plaats.

De oorspronkelijke README hoort bij die versie en kan verwijzen naar oudere repositoryadressen. Gebruik de README in de hoofdmap voor de huidige leerlijn. Externe diensten uit oude oefeningen kunnen gewijzigd zijn.

bewaarcontrole.json bevat de oorspronkelijke locaties en SHA-256-controlesommen. De inhoud van de gearchiveerde bestanden is niet gewijzigd. Open oude oefeningen vanuit deze archiefmap als projectbasis wanneer relatieve gegevenspaden worden gebruikt.
